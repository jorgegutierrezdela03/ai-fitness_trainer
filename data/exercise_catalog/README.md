# Taxonomía de referencia para evaluación

En Fase 1 se creará un catálogo pequeño de referencia para comprobar post-hoc nombres de ejercicios, grupos musculares, equipo y patrones. **No se incluye en el prompt del baseline.**

La taxonomía debe ser revisada por una persona con conocimiento de entrenamiento y no debe asumir que un ejercicio tiene un único músculo implicado. Registrar músculos principales/secundarios y sinónimos.
